## Overview

Implemented a collapsible habit name column in the grid view, improving usability on mobile where the wide sticky name column was leaving only 1-2 day columns visible.

## Feature Implemented

### Collapsible Name Column (Grid View)

Users can now collapse the habit name column down to a 32px strip showing only the habit's colored dot, freeing up screen space to see more day columns at once. A chevron toggle in the header cell controls the state.

**Behavior:**
- Expanded (default on desktop): full 225-250px name column with all controls
- Collapsed (default on mobile): 32px column showing only the colored dot per row
- Auto-collapses on first visit if `window.innerWidth < 640` (mobile breakpoint)
- State persists in localStorage under key `habit-name-column-collapsed`
- Toggle is the chevron button in the "Habit" header cell: `ChevronLeft` = click to collapse, `ChevronRight` = click to expand

**Collapsed state details:**
- Each row's name cell renders only a centered colored dot (12px circle using the habit's color class)
- Drag handle, color picker, text input, and delete button are all hidden
- Sticky positioning and borders are preserved so the column still functions as a scroll anchor
