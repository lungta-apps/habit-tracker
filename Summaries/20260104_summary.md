## Feature Implemented

### Day-of-Week Letters in Grid View

Added subtle day-of-week letters above the habit tracking grid:

- **M** = Monday
- **T** = Tuesday
- **W** = Wednesday
- **R** = Thursday
- **F** = Friday
- **S** = Saturday
- **S** = Sunday

The letters appear just above the grid border, aligned with each date column. They are intentionally subtle (10px font, muted color at 60% opacity) so they don't compete with the date numbers but provide a quick reference for which day of the week each date falls on.
