## Feature Implemented

### Numbered Completions (Long-Press to Enter Value)

Previously, habit cells were binary (completed/not completed with a checkmark). Now users can long-press any cell to open an inline numeric input and record a specific value.

**Interaction model (grid view only):**

| Gesture | Empty cell | Checkmark cell | Numbered cell |
|---------|-----------|---------------|---------------|
| Single-click | Add completion | Remove completion | Remove completion + value |
| Double-click | Toggle end line | Toggle end line | Toggle end line |
| Long-press | Open input -> type number -> save | Open input (empty) -> type number -> save | Open input (pre-filled) -> edit/clear -> save |

**Key behaviors:**
- Long-press (500ms) opens an inline `<input type="number">` inside the cell
- Enter or blur commits the value; Escape cancels
- Empty input on commit removes the completion entirely
- Numbers display as colored text in place of the checkmark
- `didLongPress` ref flag prevents the click handler from firing after a long-press
- Calendar view is unchanged
