## Feature Implemented

### Month-Scoped Habits

Previously, habits were global - creating or deleting a habit affected all months. Now each habit belongs to a specific month, mimicking a paper notebook where each month is a fresh page.

**Key behaviors:**
- Creating a habit only adds it to the current month
- Deleting a habit only removes it from that month
- Editing a habit (name/color) only affects that month
- When navigating to an empty month with habits in the previous month, a dialog appears to copy selected habits
